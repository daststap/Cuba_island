> Рабочее название — **Escape** (переименовано из Atoll на этапе 0).

План разработки для Claude Code. Это главный документ проекта: в нём цели, архитектура, этапы и критерии готовности.

## 1. Цель и рамки

**Что делаем.** Компактная «пилюля» по центру верхнего края экрана в духе Dynamic Island. Она показывает живые события (музыка, время, заряд). При наведении раскрывается в панель с инструментами: плеер, история буфера обмена, командная строка.

**Цели**
- Плавные анимации без рывков, 60 fps.
- Остров не мешает работать: клики проходят сквозь пустые области, фокус не отнимается, в полноэкранных приложениях остров прячется.
- Лёгкость: установщик ≤ 15 МБ, в простое ≈ 170 МБ RAM (из них ~160 МБ — WebView2 с GPU-процессом, без которого не работает прозрачность; исходная цель 120 МБ пересмотрена на этапе 5) и ≈ 0% CPU.
- Чистый код для портфолио: README, скриншоты/GIF, CI, релизы на GitHub.

**Не делаем в v1.0:** уведомления Windows (нужна MSIX-упаковка), ИИ-чат, запись экрана, OCR, платные функции, macOS/Linux.

## 4. Архитектура

### 4.1 Окно

Одно окно `island`, прозрачное, **больше видимого острова** (стартово 800×560 логических px). Остров рисуется внутри по центру сверху, а пустая область полностью прозрачна.

Настройки окна в `tauri.conf.json`: `transparent: true`, `decorations: false`, `alwaysOnTop: true`, `skipTaskbar: true`, `resizable: false`, `shadow: false`, `focus: false`, `visible: false` (показываем после позиционирования).

Дополнительно через WinAPI:
- `WS_EX_TOOLWINDOW` — окна нет в Alt+Tab;
- `WS_EX_NOACTIVATE` (через `focusable: false` в конфиге и `MA_NOACTIVATE` на `WM_MOUSEACTIVATE`) — окно не забирает фокус, пока не открыт ввод (снимается при открытии командной строки или поиска по буферу и ставится обратно при закрытии).

### 4.2 Click-through (ключевой механизм)

- По умолчанию все клики проходят сквозь окно (`WS_EX_TRANSPARENT | WS_EX_LAYERED`). Флаги ставим сами через `SetWindowLongPtrW`, а не через `set_ignore_cursor_events`: tao при каждом изменении флагов перезаписывает весь `GWL_EXSTYLE` (теряется `WS_EX_TOOLWINDOW`) и вызывает `ShowWindow(SW_SHOW)`. Сабкласс окна удерживает наши флаги в `WM_STYLECHANGING`.
- Фронтенд через `ResizeObserver` сообщает в Rust **текущий прямоугольник острова** (команда `set_island_rect`, в логических px относительно окна) при каждом изменении формы.
- Поток в Rust раз в ~16 мс читает `GetCursorPos`:
  - курсор вошёл в прямоугольник (с запасом 4 px) → click-through выключается и событие `island://hover { inside: true }`;
  - курсор вышел → click-through включается и `inside: false`.
- Курсор у самого верхнего края монитора в зоне острова (±150 px по горизонтали) → событие `island://edge-push`, остров раскрывается.
- Учитывать DPI: переводить физические координаты в логические через `scale_factor` монитора.

### 4.3 Позиционирование
- Монитор: по умолчанию основной, в настройках можно выбрать другой.
- Окно ставится по центру верхнего края **монитора** (не рабочей области).
- Пересчёт при `WM_DISPLAYCHANGE` и `WM_DPICHANGED`, а также при смене монитора в настройках.

### 4.4 Полноэкранные приложения
Раз в 1 с вызывать `SHQueryUserNotificationState`. При `QUNS_BUSY`, `QUNS_RUNNING_D3D_FULL_SCREEN` и `QUNS_PRESENTATION_MODE` остров скрывается, после выхода из этого режима показывается снова. Поведение отключается в настройках.

### 4.5 IPC-контракт

Все типы описаны в Rust (`serde`) и зеркально в `src/ipc/*.ts`. Имена событий — `домен://событие`.

**Команды (фронт → Rust)**

| Команда | Аргументы | Ответ |
|---|---|---|
| `set_island_rect` | `{x,y,w,h}` | — |
| `set_input_mode` | `{enabled: bool}` | — (включает фокус окна) |
| `get_battery` | — | `Battery \| null` |
| `media_get_state` | — | `MediaState \| null` |
| `media_command` | `{cmd: "toggle"\|"next"\|"prev"}` | — |
| `clipboard_list` | `{query?, limit, offset}` | `ClipItem[]` |
| `clipboard_paste` | `{id}` | — |
| `clipboard_copy` | `{id}` | — (только в буфер, без вставки) |
| `clipboard_pin` | `{id, pinned}` | — |
| `clipboard_delete` / `clipboard_clear` | `{id}` / — | — (закреплённые `clear` не трогает) |
| `launcher_search` | `{query}` | `LaunchResult[]` |
| `launcher_run` | `{id}` | — |
| `hotkeys_status` | — | `{clipboard, launcher, launcherFallback}` |
| `settings_get` / `settings_set` | — / `Partial<Settings>` | `Settings` |

**События (Rust → фронт):** `island://hover`, `island://edge-push`, `island://visibility`, `media://changed`, `system://battery`, `clipboard://added`, `hotkey://clipboard`, `hotkey://launcher`.

**Ошибки:** все команды возвращают `Result<T, AppError>`. `AppError` сериализуется как `{kind, message}`, а фронт показывает его тостом в острове.

### 4.6 Состояния острова (фронт)

```
hidden ─► compact ─► (событие) peek ─► compact
             │
             └─ hover / edge-push ─► expanded[tab]
                                    tab ∈ {home, clipboard, launcher, settings}
expanded ─ mouse leave (300 мс) / Esc ─► compact
hotkey ─► expanded[clipboard | launcher] (+ input mode)
```

- Остров прилегает к верхнему краю вплотную, скруглены только нижние углы. Наведение раскрывает его через 200 мс, упор курсора в верхний край — сразу.
- `compact`: пилюля ~ 200×36 px — часы, батарея, мини-индикатор музыки.
- `peek`: временно расширенная пилюля на 3 с (сменился трек, что-то скопировано).
- `expanded`: панель ~ 640×360 px со вкладками.
- Переходы — пружинная анимация (`motion`, `type: "spring"`), форма острова — один элемент с анимацией `width/height/border-radius` (содержимое не масштабируется), чтобы он «перетекал», а не переключался.

## 6. Общие требования

- **Производительность:** никаких опросов чаще 16 мс; всё тяжёлое (индексация, картинки) — вне главного потока; фронт не ре-рендерит остров из-за таймера прогресса (отдельный компонент).
- **Надёжность:** паника в фоновом потоке не роняет приложение (логирование + перезапуск потока); все `unwrap()` в продакшен-коде запрещены, кроме доказуемо безопасных с комментарием.
- **Приватность:** никаких сетевых запросов, кроме проверки обновлений и открытия поиска в браузере; данные только локально.
- **Доступность:** всё в раскрытом острове доступно с клавиатуры; Esc всегда сворачивает.
- **Строки UI** — только из `src/i18n/ru.ts`.
- **Код:** Rust-модули с публичным API из 2–5 функций; WinAPI-вызовы обёрнуты в безопасные функции с `// SAFETY:` комментариями у каждого `unsafe`.

## 7. Известные риски

| Риск | Что делать |
|---|---|
| Alt+Space занят системой или PowerToys | Настраиваемая клавиша, понятная ошибка. PowerToys Run перехватывает клавишу низкоуровневым хуком — такой конфликт не виден через `RegisterHotKey`, сработают обе программы |
| `SetForegroundWindow` не срабатывает при вставке | Окно Escape в этот момент имеет фокус, поэтому вызов разрешён; если нет — fallback через `AttachThreadInput` |
| Мерцание прозрачного окна WebView2 при изменении размера | Не менять размер окна: окно фиксированное, меняется только остров внутри |
| Разный DPI мониторов | Тестировать на 100% и 150% с этапа 1 |
| Высокий расход памяти WebView2 | Норма ~80–100 МБ; не держать большие картинки в DOM. Факт: ~160 МБ с GPU-процессом, который нужен для прозрачности |
| Игры в оконном режиме без рамки | `SHQueryUserNotificationState` их не считает полноэкранными. **Решено:** остров прячется и когда активное окно без заголовка точно закрывает свой монитор (рабочий стол и панель задач исключены) |
| Остров перекрывает вкладки браузера | Автоскрытие (бэклог) и настройка прозрачности |
| Браузер не публикует медиасессию в Windows (замечено у Яндекс Браузера) | Остров видит только то, что видит система (Win+A). В Chromium-браузерах нужен включённый флаг `hardware-media-key-handling` |
