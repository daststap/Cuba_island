# Changelog

All notable changes to Cuba (called Escape until 1.0.0). The format follows
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); versions follow
[SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-14

Первый релиз.

### Остров

- Пилюля по центру верхнего края, раскрывается при наведении (200 мс) или упоре курсора
  в край; пружинные анимации.
- Клики проходят сквозь пустые области, фокус не отнимается; остров прячется
  в полноэкранных приложениях.
- Часы (24/12 ч), дата, заряд батареи.

### Музыка

- Любой плеер, который видит Windows (Spotify, браузеры и т.д.): обложка, название,
  исполнитель, прогресс, кнопки.
- Обложка и эквалайзер в пилюле, peek при смене трека, свечение цвета обложки.

### Буфер обмена

- История текста и картинок (Ctrl+Alt+V): поиск, закрепление, удаление, вставка в окно,
  откуда открыли.
- Пароли из менеджеров паролей не сохраняются.

### Командная строка

- Alt+Space: программы и приложения Store с нечётким поиском, калькулятор, поиск в Яндексе,
  команды «Настройки», «Заблокировать», «Выйти».

### Настройки и система

- Вкладка настроек: монитор, автозапуск, полноэкранный режим, формат времени, горячие
  клавиши, размер истории, «Скопировано», непрозрачность.
- Иконка в трее, вопрос об автозапуске при первом запуске, подписанные автообновления.
